## 🔥 添加账单页面技术债务专项整治（2025-11-14新增）

### 问题诊断总结
**基于深入技术分析，添加账单页面存在严重技术债务：**

#### 核心问题
1. **架构混乱 - 三轨并存**
   - **V1.5生产版**：TransactionEditorScreen作为当前导航入口（统一编辑器）
   - **V1历史版**：AddTransactionScreen.kt 1900行代码仍在编译（作为组件参考）
   - **依赖错位**：新页面仍依赖AddTransactionViewModel + AddTransactionUiState（兼容层）

2. **状态管理三重奏**
   - TransactionFormState（业务表单状态）
   - EntityEditorState（UI元状态）
   - AddTransactionUiState（兼容层，75+字段）
   - 通过combine同步，每次改动需修改多处

3. **ViewModel职责过载**
   - AddTransactionViewModel统一处理新增/编辑模式（1000+行代码）
   - 注入10+个依赖（Repository、UseCase、DataStore、UserApi等）
   - 包含12个viewModelScope.launch，缺乏协程Job管理
   - 注：EditTransactionViewModel已被删除，所有逻辑集中在AddTransactionViewModel

fun EntityEditorScaffold(
    title: String,
    isEditMode: Boolean,
    onBack: () -> Unit,
    onSave: () -> Unit,
    isSaving: Boolean = false,
    content: @Composable ColumnScope.() -> Unit
) {
    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text(title) },
                navigationIcon = {
                    IconButton(onClick = onBack) {
                        Icon(Icons.Default.ArrowBack, "返回")
                    }
                },
                actions = {
                    TextButton(
                        onClick = onSave,
                        enabled = !isSaving
                    ) {
                        if (isSaving) {
                            CircularProgressIndicator(modifier = Modifier.size(16.dp))
                        } else {
                            Text(if (isEditMode) "更新" else "保存")
                        }
                    }
                }
            )
        }
    ) { paddingValues ->
        Column(
            modifier = Modifier
                .padding(paddingValues)
                .fillMaxSize()
        ) {
            content()
        }
    }
}
