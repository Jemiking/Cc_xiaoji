## 概述

记账模块是本项目最复杂的功能模块，涵盖了个人财务管理的方方面面。模块采用 **Clean Architecture + MVVM** 架构，体现了领域驱动设计(DDD)的最佳实践。

## 架构亮点

1. **模块化设计**：通过 `LedgerApi` 接口对外暴露功能，实现模块间解耦
2. **领域驱动**：UseCase层封装业务逻辑，ViewModel只负责状态管理
3. **可扩展性**：解析器工厂、导入导出接口等采用策略模式，易于扩展新平台
4. **性能优化**：分类缓存、分页加载等机制确保大数据量下的流畅体验
